# Las capturas se envían a Telegram, con nombres de jugador incluidos

Cada mejora iniciada y cada error que detiene al bot envían una captura al chat de Telegram del propio jugador. Las capturas pueden mostrar el nombre del jugador y no se ocultan: es una decisión expresa del jugador, y solo van a su chat. Es la única salida de capturas fuera de la máquina; el token y el chat se guardan como secreto y no aparecen en ficheros legibles ni en registros.
